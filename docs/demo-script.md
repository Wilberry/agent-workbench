# Demo Script

This script outlines a short demo to showcase key platform capabilities.

1. Create Organization and Invite Member
2. Create a new Agent (system prompt, model)
3. Create Agent Version (workflow, system prompt)
4. Quick Test the version using `Quick Test` UI
5. Run an evaluation dataset and show results
6. Create a run and open Run Detail; demonstrate realtime updates
7. Show Trace Explorer and execution graph
8. Publish to Marketplace (if org-scoped)

Timing: ~8-12 minutes

Notes:
- Use a seeded demo org and agent to avoid repetitive setup.
- Ensure OpenAI keys are configured for realistic responses or use mock provider for offline demos.
